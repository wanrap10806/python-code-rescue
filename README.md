# 🐍 Python Code Rescue

An interactive browser-based Python coding and debugging challenge for Class X students.

The application allows students to practice basic Python programming directly in their web browser without installing Python.

## 🎯 Features

- 🐍 Run Python code directly in the browser
- 💻 Coding challenge
- 🐞 Debugging challenge
- 🔮 Output prediction challenge
- ⭐ Automatic scoring
- 📊 Challenge progress indicator
- 📱 Responsive design
- 🌐 No backend server required

## 🧩 Challenges

### Challenge 1 — Coding

Students write a Python program that:

- Takes two numbers as input
- Adds the numbers
- Displays the result

### Challenge 2 — Debugging

Students identify and fix a Python syntax error.
